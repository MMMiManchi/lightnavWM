## 已复核的结论

用户列出的样本覆盖、33 次不变预测、11 次修正、同样 20 次命中均与保存的实际数组一致。当前仍不能据此验收“陌生分支到下一地点”的预测能力。

需要明确两处参照关系：

- 20.49° 是场景残差相对**基础预测**的特征空间角度限制。基础预测可能已混入历史后果，不总是当前特征。58.01° 是先平均当前—目标余弦再取反余弦；逐条角度的平均为 57.21°。这些均不是机器人转角。
- 33 次不变指新增场景头没有改变“只读记忆”的预测，不表示这 33 次全部复制当前帧。按基础预测重新计算，44 条里仍有 43 条真实目标超出该残差球的精确表示范围，平均基础—目标角度约 48.70°。这限制特征拟合，但不意味着检索必须精确重建目标才能正确。

不应简单把所有模块解冻：固定 encoder 有利于保持记忆键空间一致，冻结 LightNav 有利于固定执行条件。需要改变的是转移模型的训练目标、数据和能力验收。仓库已有非有界残差的 `ResidualEventWorldModel` 与完整特征解码的 `EventLatentWorldModel`，此前它们也没有取得优势，因此扩大残差或再写一个更大的预测头不足以解决问题。

3 个同历史多出口组中：

- `PX4nDJXEHrG`：两个方向的后果被标为同一目标地点，可作多正例，不能强行作为彼此的负例。
- `29hnd4uzFmX`：相同视觉历史和相同输入方向出现不同目标地点；需要核对技能终止、后续路径和弱标签，不能直接假定这是标签错误，也不能当作唯一确定的转移。

按全部视觉历史分组，fit 一共检出 3 个“相同历史/方向、不同目标地点”组。它们提示现有输入可能缺少执行策略/终止条件，或标签/事件边界需要复核。多模态真实后果应保留不确定性，而非一律删掉或平均成一个确定状态。

原 44 条图库计分本身是合法的离线表示诊断，正确后果参与计分不等于泄漏进预测输入。但它不能直接代表运行时已有这些经历。

## 下一轮实施与验收顺序

1. **先定义并采集事件分支，而非增加相邻帧。** 从同一个可复核的起始状态，分别执行当前真实可见的多个出口；绑定固定局部技能策略、来源、执行回执和事件终止约定。记录穿门/进入新区域/下一决策点后的实际观察。预算、阻挡、局部 STOP 和未确认到达单列，不用固定距离截断冒充下一节点。离线分叉采集可以使用恢复和诊断标签，在线策略不能读取未执行分支的真值。
2. **消除输入与后果定义混杂。** 保存入口外观与局部方向、执行前已知的技能描述/版本，固定终止约定。先检查实际是否走入请求分支。不同出口到同一地点允许多正例；相同输入的真实多后果用不确定性建模。对照训练优先采样真正可区分的分支组，不能让大量单出口重复轨迹主导。
3. **恢复转移主干的离线训练。** 冻结视觉目标空间和 LightNav，训练事件状态编码、分支条件转移及完整未来状态解码。先用已有不受小残差输出球限制的实现作基线，评价无匹配记忆时的预测和分支消融；场景 adapter 作为该模型的适应组件，不能只校正一个退化的基础预测。保留确定性基线，多假设模型另验校准，不能凭随机采样宣称处理了未知。
4. **先证明选项改变了有用的预测。** 在同一来源状态的各分支上，对照真实后果、复制当前状态、仅真实记忆、无分支/打乱分支输入和正常预测；排除同目的地多正例。主指标包括下一事件特征、分支后果区分、实际历史支持覆盖与缺支持时的校准。闭集 44 条降为历史诊断，不再作为主验收。
5. **在查看新结果前封存新 query。** 登记场景/路线和访问顺序，区分旧开发研究、模型开发和最终封存测试。若无可证明未接触的房屋，应如实称新路线/新目标测试，不称新房盲测。当前没有生成或声称已有新的盲测集。
6. **再检验越走越熟与导航。** 每次先预测、真实执行后计分，再写回和更新；后续用不同目标/路线比较。有无适应共享相同观察查询与经验预算，另做重复种子的真实导航。旧支持集损失下降不能替代新 query 进步。Harness 的节点触发、主动观察、回溯、进度和 STOP 单独验收，不能用多次参数发布或阶段打勾代替选路收益。

原 0.6 秒经历保留为执行/持久化辅助数据，不改标为事件到达。此前全部实验与源码快照保留；本轮不再重复跑同一批短时导航来主张核心能力改善。
