## 交叉核对

- 11 个候选共 47 个成员 span；每个 span 的起点和已观测终点 RGB 资产均存在，所引用的 observation ID 能映射到对应 episode 与 route group。
- 2 个候选的最大成员间水平距离超过 0.75 m（0.988 m、1.584 m），接触图也显示出明显异质性。原先基于阈值邻接的连通分量确有链式合并风险。
- 4 个候选覆盖多个 route group，9 个覆盖多个 episode；其中多个 episode 但只有一个 route group 的候选不提供独立路线多样性。
- 当前 fit/dev 的 `route_group_id` 与 `route_geometry_hash` 均未发现跨 split 重复。train_dev 仍然只能用于开发/审查，不得并入 train_fit。
- 即便跨 route group 且画面看起来相近，数据仍只含各路线实际走过的结果，不含决策时完整的备选出口集合。严格确认的分支候选集合仍为 0。

## 下一步判定

先将两项疑似链式合并拆分审查，并对其余三个“多 route group 且直径未超阈值”的候选核对完整路线几何与时间顺序。只有当成员的节点视角、路线到达方式和离开轨迹都支持同一物理决策点时，才可把它们列为“跨路线重访 proxy”；仍需将未走出口标为 unknown。不要据此训练 TSSM，也不要把视觉筛查结果写回正式 transition 标签。
