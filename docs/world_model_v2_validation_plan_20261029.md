## 4. R1：命令先验＋动作调制的未来状态模型

### 4.1 输入、输出与已知命令先验

先保持一步：

```text
RGB_t --冻结同版本SigLIP--> z_t ∈ R^1152
u_t = (v_mps, w_rad_s, dt_command_s)
b_t = (v*dt_command, 0, wrap(w*dt_command))   # 复用现有kinematic_delta和联合STOP阈值

动作分支：a_t = MLP(normalize(u_t), v*dt, w*dt, stop_flag)
视觉分支：h_t = Linear/LayerNorm(z_t)
动作调制：h'_t = (1 + gamma(a_t)) * h_t + beta(a_t)

F(h'_t, a_t) -> (r_forward, r_left, delta_z)
预测实际平移 = b_t.xy + r_xy
预测yaw = b_t.yaw                         # 当前接口先不学习yaw残差
预测未来视觉 = z_t + delta_z
```

动作调制是待实现方案，作用是让动作参与特征变换，而非只在1152维向量末尾拼3个量；它不保证模型会使用动作。初版隐层64，动作分支32，单模型目标参数≤0.2M，需实现后按真实参数数目报告；不先增大基座。

残差标签在线外由现有真值计算：`r_xy = measured_delta_xy - b_xy`。这是派生训练目标，不回写数据、不更改schema、不把b当真实执行结果。残差参数化不增加标签信息，仍可能预测均值，需要对照证伪。

真实联合阈值STOP在当前Habitat中不积分位姿，可用确定性分支令预测位姿增量为零；这必须作为**规则贡献**单列，且action-only等对照使用相同规则。不能将规则修复的24条STOP记为学到动作。低线速度转弯不使用额外“置零”规则，保留真实小v和可学习残差。未来视觉头不因STOP被强制不变，终止观测可能受渲染/物理窗口影响，仍以实际标签验证。

当前命令积分yaw近乎精确，先走解析路径，不将其复现记作世界模型贡献。出现已证实的yaw残差需求后再研究该头。

### 4.2 信号、尺度与训练分布

保持冻结视觉teacher，目标来自真实下一帧特征和前后位姿：

`L = L_motion_residual + λ_z * L_future_latent`。

- `L_motion_residual`：forward/left残差的Smooth L1，按fit残差尺度归一化后训练；输出还原为米。尺度只从fit得到并设明确正下限。推理报告继续用原始米制Huber、幅度误差、向量误差，不改评测定义。
- `L_future_latent`：对`z_next-z_current`做按fit统计的尺度归一化MSE；方差下限防止几乎不变维度被无限放大。teacher冻结、不引入一个可塌缩的共同训练编码器。原始1152维MSE/余弦、预测变化幅度、检索指标都保留。
- λ固定为1用于首轮，因为两项已按fit尺度归一化；记录每头梯度/输出尺度。若其中一项失败，再单独做有明确假设的权重对照，不隐含扩大搜索。
- 第一轮R1用自然分布，先判断结构/目标是否有用；若稀有动作仍失败，才单独比较受限分组重加权。权重仅按fit最终命令组频数计算，上限3，写入实验配置；dev始终原始分布，不重采样。这样不会把重采样收益归给结构。
- 不以“不移动”自动生成碰撞标签，不以目标测地距离当在线输入。可从标签定义“执行位移明显低于命令”，但只称运动残差，不称碰撞/失败/导航进展。

全局pooler向量可能缺失局部通行几何，这是待检验的表征瓶颈。若visual+action不优于action-only，不先盲目加容量。后续可将“短历史”或“空间token”作为二选一的独立假设；先核验现有缓存是否已含相应字段，不具备就明确新增特征提取的成本与范围，不将本轮缓存当空间特征。

### 4.3 最少对照与可证伪条件

固定比较：A零增量、B命令积分、C fit常量、首版冻结、R0训练过程对照、R1 action-only残差、R1 visual+action残差。R1两种模型使用相同动作规则、训练预算、分组策略与损失尺度；尽量匹配参数量，并单列真实参数和运算成本。

视觉价值证据来自visual+action相对action-only，而不是相对零增量。动作价值检查包括：

1. 正常输入、动作置换（仅评估时在有支持的动作组内置换）、去掉动作；同一标签比较误差变化。这是依赖性/破坏性对照，置换可能造成分布外输入，不能单独证明正确动力学。
2. 固定同一z，取fit支持范围内的少量动作：STOP、低v转弯、前进。检查响应曲线、符号和幅度连续性。未执行动作没有真值，仅属合理性检查，不能写成反事实预测准确率。
3. 有真实匹配样本时，在相似视觉状态中比较不同已执行动作的预测/真值，按episode/scene聚合；近邻并非完全相同状态，不夸大因果结论。

建议预先登记的阶段验收目标（不是修改现行数据准入规则）：

- visual+action在自然dev的scene宏平均平移Huber和向量误差都优于命令积分、fit常量与action-only；至少2/3 seeds方向一致。可将≥10%的相对改善作为有实质意义的目标，未达到不包装成稳定收益。
- 对近静止、低线速度转弯、真实移动三组，报告均值/P90及scene内分布；不得靠真实移动组收益掩盖近静止进一步恶化。建议每组平均平移向量误差不超过该组强基线误差加 `max(强基线误差×5%, 0.001m)`，避免接近零时除零或夸大微小误差。该1mm为设计容差，必须在实验启动前固定，不能见结果后放宽。
- 阈值STOP由规则保证，单独报告规则前/后，不纳入“视觉贡献”；低v转弯是学习验收重点。
- 未来视觉：原始MSE不差于copy-current，同时未来变化方向/幅度和检索优于当前状态query；不能只凭MSE低于0.45%的首版提升宣布成功。预测残差为零的比例、方差也报告。
- 按scene/route聚合；场景bootstrap置信区间作不确定性说明，只有8个dev场景，不以逐帧数假装统计独立。不通过则暂停对应闭环分支。

R0/R1为新模型训练提案，本轮未执行。不会直接把首版继续多训当成已验证优化。

## 5. R2：预测引导记忆，保留世界模型研究主线

记忆只存当前episode、决策时已观察到的经历：

`M_j = {z_j, RGB_j, executed_u_j, z_{j+1}, RGB_{j+1}, original_frame_ids, time_order, prediction_error}`。

只有执行后观测已到达才能封闭转移；reset清空。query为基座建议动作条件下的预测未来向量`q_t = z_hat_{t+1}(z_t,u_proposal)`，优先检索过去已观察的`z_{j+1}`，返回相应真实RGB及历史上下文。先不依赖全局位姿；若以后加入空间约束，必须使用在线里程计/自估计并披露误差，不能用Habitat真值位置。

离线对照：最近历史/随机历史、当前z_t query、预测未来query；真z_{t+1}仅作oracle上界。候选仅限j+1≤t，排除当前/最近重复帧或去重，固定候选集并报告空候选率。

检索评价：

- 未来观测相似度、相对oracle候选排序的Recall@k/MRR、历史覆盖率、重复率。
- 相似度使用冻结特征，与训练目标有关联，不能把它当作独立导航能力证据；补充少量盲查例子及现有日志中的实际后果对照。
- 不把“视觉像下一帧”自动叫作“有助于导航”。只有R4闭环可验证后者。

先以k=2个历史片段、最近帧排除窗口5步作为初始设计，固定后比较，不通过检索结果反复挑参数。帧数/时长按真实序列定义，不把RVQ10点当10个候选动作。若候选集太小或序列不足则原基座回退，不补造记忆。

## 6. 怎样接到冻结LightNav：具体控制流

```text
当前RGB + 原始指令 + 原历史
        ↓
冻结LightNav生成一次原始轨迹 → 现有控制器得到建议命令u0
        ↓
独立冻结SigLIP + 新世界模型(z_t,u0) → 未来query
        ↓
从当前episode过去记忆检索真实RGB片段
        ↓
历史适配器构建显式视频segments（保留当前/最近上下文、时间和token预算）
        ↓
同一个冻结LightNav再推理一次 → 现有RVQ解码/速度映射 → 命令u1
        ↓
环境执行 → 真实下一RGB + 最终执行ack → 更新记忆
```

这是新增**独立实验策略**的提案，不给基座权重接一个未经训练的1152维输入。LightNav不直接消费SigLIP latent；latent负责预测和检索，进入基座的是历史中真实存在的RGB。指令继续走原始语言入口；第一版世界模型不另加文本编码器，不能称为指令条件世界模型。

用u0预测的query若导致二次输出u1发生变化，不假装预测对应u1；记录proposal、query所用命令、二次输出和最终ack。第一版至多一次检索/重推理，不循环自我优化。事后预测误差必须针对最终实际执行命令计算；如服务端替换动作，旧proposal预测标为不匹配，不错误计分。

### 6.2 历史适配的关键风险

SlowFast按完整episode的绝对索引采样，抽帧后伪造连续帧会改变时间语义。检索适配需要显式片段、原始帧ID、正确pool配置与prompt对应。基座是否能理解这种历史重分配尚未验证，属于闭环风险，不称接口现成可用。

只替换历史预算中的部分远期片段；保留当前/近期片段和时间先后，去重，不给预测latent渲染假RGB。processor产生的实际token数必须记录。检索sample初期关闭相应ViT缓存或使用严格片段/帧身份键，避免把重组片段错误命中原tubelet缓存；缓存关闭成本纳入公平比较。

未来训练时用的冻结SigLIP必须在导航时逐帧在线计算同版本特征；现成离线缓存只可重放既有轨迹，不支持偏离轨迹后的闭环。需要新增在线冻结编码器适配器、预处理/权重校验与耗时记录；不需要重新提取训练缓存，但也不能声称闭环不需视觉编码成本。

## 7. R3/R4：从影子模式到可解释的导航实验

R3仅预测与记忆日志，返回原始u0，行动序列须与关闭模式一致。检查：RGB处理、episode reset清空、时序、无未来泄漏、proposal与ack关系、STOP/解码回退、服务端覆盖、额外显存/耗时。无有效记忆、非有限输出、超预算均回退原建议动作；不可偷偷将恢复动作设为零速度，因为当前Habitat零速会终止episode。

R4最少闭环组：

| 组 | 用途 |
|---|---|
| 原始LightNav一次推理 | 原始基线 |
| 同历史重复推理，最终用第二次结果 | 控制额外推理调用影响 |
| 等预算最近/随机记忆＋二次推理 | 控制增加历史/换帧的影响 |
| 当前状态query记忆＋二次推理 | 对照不依赖世界模型的检索 |
| 预测未来query记忆＋二次推理 | 检验世界模型预测是否额外有用 |

检索组保持相同片段数和实际视觉token上限；二次推理组相同解码预算。单独列调用次数、视觉编码、缓存策略和P50/P95时延，不能把更多算力带来的收益全部归给世界模型。

固定episode allowlist与seed、传感器高度0.5m/半径0.1m和现有500步上限（启动前核对配置哈希），相同服务端early-stop和runner强制预算STOP；区分模型STOP/解码回退/预算STOP/服务端终止。先在官方train中预留的导航开发路线上做故障检查；val_seen/val_unseen不参与训练或离线归一化。闭环开发集、最终保留评测的具体episode清单在启动前冻结，不能反复看最终集调参。

建议先固定60个episode、覆盖至少6个可用场景作配对闭环开发；数量取决于可用清单，未核验前不是已选实验集。开发检查通过后，再决定最终评测规模，不因小样本SR上升直接宣布有效。

报告SR/SPL/NE/nDTW（现有定义不变）、路线/scene宏平均与配对不确定性；非有限NE不静默丢弃。额外报告原失败样本恢复、原成功变失败、循环/原地转动/提前STOP、动作变化率和记忆触发率。该机制只能在闭环数据支持后宣称提高导航。

## 8. 后续动作选择/恢复为什么放在最后

当前10点是一条轨迹的时序，不是10个可选动作。若以后要规划，只能明确构造独立候选（原命令、低速版本、有限左右旋转等），并为这些候选取得相应实际后果数据；当前on-policy离线数据没有同一状态的全动作真值，也不能为未执行候选伪造标签。

因此第一版接入通过真实历史RGB影响冻结基座，不直接让残差模型重排动作。再观察到可靠的运动残差与不确定性证据后，才设计“预测受阻→重新观察/恢复”；不读取真实目标距离作在线进展，不将零速当暂停。

## 9. 建议的后续任务拆分

1. **先做R0独立训练过程对照入口**：只新增实验配置/脚本，保留首版与所有既有结果；固定数据快照、更新数、seed、checkpoint选择与输出路径；不改全局训练准入。验收是可以解释训练曲线及原失效组是否变化，而不是必须得到正结果。
2. **再做R1独立目标/动作分支**：命令残差与未来latent、fit尺度、action-only对照、STOP规则归因；保留原评估定义。先合成接口/小batch前向反向验证，随后执行登记的实验，不同时加历史/语言/空间头。
3. **R2过去记忆离线评估**：实现因果候选集和query对照，优先验证未来视觉表征是否有检索价值。
4. **R3独立policy/env包装器**：明确最终ack和在线SigLIP，显式历史sample适配，先影子模式；关闭时验证原行为一致。
5. **R4等预算闭环实验**：只有通过相应门槛后开展，冻结数据集和比较组，保存失败结果。

现阶段首要任务是第1项；不是立即训练更大模型，也不是直接改LightNav动作。本文没有实施上述任务，不新增采集预算、不启动下一轮实验。
