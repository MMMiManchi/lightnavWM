# 自主节点发现：官方 viewpoint 作离线监督，运行时不读取官方图

日期：2026-11-04。本文明确用户进一步提出的目标与后续数据任务，是设计说明，不代表节点发现模型已训练或验证。

## 目标与节点来源

目标系统从连续视觉观察中发现决策区域、自主建立节点、判断回访，并在这些节点上调用世界模型与记忆。运行时不读取官方 viewpoint 名单、官方相邻节点、真值 pose 或完整场景图。

官方 viewpoint 用于离线挑选和对齐训练锚点，替代当前自采代理节点中不稳定的坐标聚类和跨路线 ID 判断。其作用是帮助标注学习目标；最终节点发现模块主要消费当前及过去 RGB。官方 ID 是训练记录的来源标识，不是部署时需要预测的封闭类别编号。

官方 viewpoint 是相机采样位置，投影到地面、核对可达性后才能当机器人锚点。它的几何位置和 ID 比当前代理聚类更便于审计，但“是否属于决策节点”仍需筛选和证据。度数至少 3 不等于语义岔路。

## 需要学习的能力

| 能力 | 输出 | 监督和约束 |
|---|---|---|
| 节点发现 | 正常行走、接近/处于决策区域、暂不可确认；置信度 | 从连续画面判断，避免只对单张正例照片分类 |
| 类型辨别 | 分岔、门口/房间交界、明显转弯或 unknown | 只对有依据的类型训练；指令停止位置单列任务条件 |
| 可见出口提议 | 当前观察支持的方向/入口及不确定性 | 来源是感知；未看到的出口不能根据官方完整邻接提前补进在线输出 |
| 回访识别 | 与自己已建立的某个历史节点匹配，或新建节点 | 使用视觉描述和因果历史；考虑进出朝向变化 |
| 时间上的稳定触发 | 同一次停留只触发一次，离开后可在回访时重触发 | 用时序模型/状态管理处理，评估漏检、重复建点和错误合并 |

主线输入保持现有 RGB 契约。冻结预训练视觉编码器后，可训练小型时序节点发现头与描述子/方向头；不要求从零训练全部视觉能力。若将来加入 depth、里程计或 SLAM，作为明确的传感器扩展单独对照，不把离线真值位姿带到输入。

## 官方锚点怎样变成训练数据

1. **先筛选有决策意义的区域。** 综合官方图的去冗余通路、空间/房间交界信息和可达几何判断，而非仅看邻居数量。房间内部多个扫描点互连、直走廊上的重复点都不能机械地标成分岔。无法确定的类别保留 unknown，并生成可人工核验的证据清单。
2. **从官方名单中选对应锚点。** 一个决策区域可由附近合适的官方 viewpoint 表示，但不要求真实决策中心恰好等于相机采样坐标。保留区域与锚点的关系、投影误差和选择依据。
3. **与本项目观察配对。** 优先将现有带 pose 标签的 Go2 轨迹映射到这些区域，引用实际存在的 RGB；缺图保持缺失。官方高机位全景可以辅助预训练或标注，最终须验证 0.50 m 相机及当前视野中的表现。
4. **构造连续片段和负例。** 正例包含接近、进入、停留、离开的过程；负例包含普通直走廊、房间内部和视觉类似但不构成决策区域的位置。只收节点照片没有足够的负例、触发时机和上下文。
5. **核对当前是否可观察。** 完整图能知道某处有隐藏出口，但当前视野未必能判断。记录可见性；不把不可观察的完整拓扑当成单帧模型应确定输出的答案。允许模型请求主动观察再确认。
6. **隔离标签和输入。** 官方节点/邻接、GT pose、房间几何、未来观察只供离线标注或监督。输入只含本次决策时已发生的观察与允许历史。与 `online_input.py` 保持一致。

由此得到的样本是“视觉历史→是否到达决策区域/可见方向/回访关系”。这与按固定 viewpoint 类别编号分类、直接从官方邻居名单取动作，是不同的训练目标。

## 运行时链路

```text
当前/近期 RGB + 已允许的历史
        ↓
节点发现与回访识别
        ↓
进入决策区域 → 自己建立/更新 online_node_id
        ↓
感知当前可见入口和方向
        ↓
Harness 调用世界模型与真实记忆，选择局部行走目标
        ↓
LightNav 实际执行
        ↓
新观察确认到达/失败，更新自主形成的图与经历
```

正常行走过程可继续由 LightNav 驱动，节点模块观察实际历史并触发高层决策。世界模型预测的是当前分支的后果；节点模块负责发现决策区域，两者可以先分别验证。

运行时形成的可见方向或局部子目标也是候选，但由机器人感知产生，不是查官方候选表。已建立的在线记忆图可以保留，供回访和回溯；“不查官方图”不等于每次丢掉自己建立的地图。

## 训练成功应怎样判断

必须在未参与训练的场景和完整轨迹上，测试时不加载官方节点/邻接后仍能工作：

- 决策区域级的检出率与精确率，包含提前发现和漏检距离。
- 普通走廊/房间内的误触发率；同次停留的重复节点数。
- 不同朝向回访时的匹配正确率，以及错误合并两个节点的比例。
- 已观察出口的提议正确率与可执行性；不可观察情形单列。
- 固定下游控制器后，发现节点对实际路线选择、路径和预算的影响。

这些指标从官方/人工核验标签离线计算，标签不喂给模型。仅展示训练集照片分类准确率，无法证明陌生环境中的自主节点发现。

## 下一步唯一任务

**先做官方锚点支持的节点发现训练集和小样例核验。** 交付决策区域/类型依据、选中的官方锚点、现有 RGB 时间片段、普通位置负例、可见性与回访标签、划分和 unknown 清单；不要先扩采大量点，也不要把所有度数较大的 viewpoint 都标为正例。

数据确认后训练独立的时序节点发现模块，在未见场景上评估，再接世界模型/Harness。能否泛化由上述测试决定；采用官方标注源本身不保证已经学会自主找节点。
