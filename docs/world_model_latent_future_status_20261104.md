## 用户要的训练目标

主目标是：根据当前及过去真实视觉观察，以及执行前可定义的一个分支，预测走到下一事件区域时的潜在状态特征；以预测特征检索真实历史经验，再为 Harness/LightNav 的决策提供依据。

这里的“特征标识”理解为可比较、可检索的连续向量或少量特征 token。它不是官方 viewpoint 编号，也不要求先生成未来 RGB 或人工房间名称。

节点发现器输出接近/进入等事件，负责提供决策时机和地图候选；未来状态预测器输出分支条件的未来特征。两者是不同模块。前面关于冻结 encoder、小型时序节点发现器的建议属于辅助前端，不能替代世界模型的主训练任务。

## 已明确的接口方向

```text
当前/近期 RGB + 已发生的行为/观察历史
                ↓ 冻结视觉编码器、历史状态模块
              当前 belief h_k
                +
执行前可定义的分支 c_k（相对出口、局部目标、技能策略与终止约定）
                ↓ 条件潜在状态转移
          未来潜变量的一个或多个假设
                ↓ 特征预测/投影头
          预测的下一事件特征 f_hat_next
                ↓ 与真实记忆键同一表示空间
             查询真实经历、辅助决策
```

训练目标来自真实后果：

```text
实际到达下一事件后的 RGB/多视角片段
                ↓ 固定的 teacher 表征与聚合规则
              f_target_next
```

训练只给实际走过的分支提供后果监督。未来片段只在目标侧使用，不能进入预测时的输入；事后完整执行命令也不能假装成执行前已知条件。没有走过的出口保持 unknown。截尾记录不能伪造为已到达下一节点。

如采用 TSSM：部署时的 prior 根据历史和分支预测未来潜变量；posterior 只在训练或真实后果到达后使用。内部随机潜变量与输出的检索特征不是同一接口；预测头要把潜变量映射到真实记忆采用的目标空间。

官方节点在这里主要用于离线切分和配对有意义的事件尺度，运行时不提供官方 ID、坐标或邻接。已有 1,525 次训练侧有图进入，也不等于已经有 1,525 组合格的“起点—执行前分支—下一事件特征”训练转移，仍需实际构造、去重和检查。

## 架构是否定版

**事件级潜在预测器 v1 的输入、表示和训练契约已固定，并完成第一轮可复现实验；整体系统仍处于研究验证阶段。**

设计稿首选事件尺度的分支条件随机潜在状态模型，保留确定性预测器基线。首轮采用已审核 SigLIP 1152 维特征、宽度256/4层/8头的历史 Transformer、64维随机状态和 prior/posterior；8卡并行运行3 seed的带/不带分支 TSSM及1对确定性模型。原稿512宽度/6层等仍是未验收候选，没有被宣称为最优。

首轮已将以下契约记录在配置及训练文档中，后续修改需要登记为新实验：

1. **状态和预测终点**：下一事件区域的哪段真实观察、朝向或多视角聚合；终止/截尾如何处理。
2. **分支条件**：执行前能获得哪些描述，所代表的执行策略和终止条件；不得用官方邻接充当在线候选。
3. **表示空间**：teacher、向量/token 形状、聚合和归一化；预测输出与真实记忆键必须兼容。现有 SigLIP 缓存和草案中的 DINOv2 空间特征不能自动视为已统一接口。
4. **模型与目标**：确定性基线及 TSSM 的第一版配置；未来特征对齐、检索对比目标，以及随机版本的 KL 等项如何计算，如何防止当前状态复制或忽略分支。

验收应看：预测 query 是否比当前状态 query、近邻后果和不使用分支的模型更能检索到真实未来经历；同一状态换分支是否产生有依据的差异；在留出场景和固定下游控制器中是否有用。仅节点分类准确率、特征重建 loss 或 posterior 重建结果不能代替这些检验。

## 本轮结论

主任务仍是“分支条件的下一事件特征预测”，节点发现属于辅助模块。第四版标注已用于构造614组训练、44组开发转移；全部8组训练、checkpoint和推理包已完成，原始记录未改。三 seed TSSM 带分支的开发场景宏余弦0.3486，无分支0.3487，复制当前特征0.5456；尚未显示稳定分支收益。下一步应分析表示与监督，而不是将当前版本宣称为已能改善导航的世界模型。

跨 episode 历史更新：`scene_memory.py`、`event_memory.py` 已提供持久经历库、原指令与实际执行/后果记录、历史特征三元组和记忆增强预测接口。冻结原模型，在开发记录重放中跨episode历史使离线 R@1 从22.73%到40.91%，主要来自熟悉路线/分支；新路线未显示收益。详见 `docs/world_model_cross_episode_history_20261104.md`，不能据此宣称神经读写模块、在线参数适应或实机熟悉化已经完成。

后续优化已按用户指令执行：`event_residual_v2_20261104_01` 与 `event_anchored_v3_20261104_01` 各完成 8 组 GPU 实验。v3 仅校准版本按内部验证选中，同历史直接检索 R@1 为38.64%，该版本为45.45%；44次查询增加3次命中、没有减少，宏余弦0.6146到0.6234。完整状态残差版本为43.18%，未优于校准版本；无历史时显式保留当前特征，新路线子集仍未见改善。这是熟悉分支的记忆利用改进，不能称冷启动世界模型已通过验收。

`event_runtime.py`、`smoke_event_lightnav.py` 已接真实冻结 LightNav-0。完整41帧输入下，原始任务和局部目标均得到有效RVQ/10×3航点，目标改变保留原生SlowFast历史。旧回合视觉重访在实际仿真第40步触发局部目标；未验收的局部STOP由Harness接口拦截。实验边界、源码及最终仿真结果见 [world_model_optimization_v3_20261104.md](world_model_optimization_v3_20261104.md)。原有LightNav历史采样尚未改为事件采样，完整语义规划、主动观测、回溯和导航成功率对照仍待后续实现。
