# 2026-11-06 世界模型首轮训练结果

已用当前数据完成首轮训练及对照：八组从头训练，四组沿用已有世界模型权重的低学习率微调。
有可加载的模型权重，训练与导出接口均通过检查；**目前尚未找到同时具备可靠未来特征预测和出口区分能力的版本**。
这次实验支持先用小数据验证，但不支持把训练损失下降当成世界模型已经可用于选路。

## 数据和训练范围

使用 `event_branch_release_20261106_02` 的 90 条 fit、36 条 development 独立事件。
fit 覆盖 27 栋房屋，development 覆盖 6 栋，房屋不交叉；两出口目标不同、且输入历史完全一致的
可比较起点分别为 38、15 个。同一房间的多个视图作多正样本，合理会合的出口不强行作负样本。

只有 fit 样本贡献梯度。SigLIP 的权重及 fit-only 标准化坐标保持冻结，LightNav 没有加载或更新。
封存测试没有打开；开发集用于挑选检查点，因此这份结果不是盲测，也不是导航成功率。
没有通过“正确未来就在库里”的开发图库检索来宣称预测成功。

本轮训练的是世界模型预测头：输入八帧过去/当前视觉特征和一个候选出口的相对方向，
输出 1152 维归一化的隐式未来视觉特征。训练时 posterior 可以看实际未来作监督；
发布接口仅调用 prior，推理不需要未来图像、官方 viewpoint 名单、邻接表、世界坐标或区域标签。

## 对照设计

第一轮八组：

- 112 万参数小模型，128 宽、两层；有/无出口方向各用种子 11、23、47。
- 487 万参数现有规模模型，256 宽、四层；有/无出口方向各用种子 11。

最多 2000 次更新，batch 32，学习率 0.0002。模型按房屋/起点/出口平衡采样，
按预先约定的开发集房屋宏平均未来特征余弦相似度选检查点，并保留全部曲线。

第二轮四组：从同一份已有世界模型权重开始，有/无出口方向各用种子 11、23。
确认旧权重和新数据的 feature mean/scale 完全相同，学习率降到 0.00002，最多 1000 次更新。
微调前的第零步也可被选为最佳检查点，避免强行保留退化的新权重。

## 主要结果

下表使用各组按约定选出的检查点，多种子行取均值。
余弦相似度是特征指标，**不是成功率百分比**，越高越好。
出口匹配只比较同一节点的两个真实未来：正确对应优于交换对应记 1，反之记 0，完全一样记 0.5。

| 方法 | 开发集未来特征相似度，房屋宏平均 | 出口匹配比例 |
|---|---:|---:|
| 复制当前特征 | **0.473** | 50%，全部无法区分 |
| 训练集经验近邻，加当前出口方向 | 0.173 | 80%，12/15 |
| 从头训练：小模型，有方向，三个种子 | 0.283 | 46.7% |
| 从头训练：小模型，无方向，三个种子 | 0.304 | 50%，全部无法区分 |
| 从头训练：现有规模，有方向 | 0.292 | 53.3%，8/15 |
| 从头训练：现有规模，无方向 | 0.311 | 50%，全部无法区分 |
| 已有世界模型，微调前，有方向 | 0.343 | 60%，9/15 |
| 已有世界模型微调，有方向，两个种子 | 0.369 | 43.3% |
| 已有世界模型微调，无方向，两个种子 | 0.372 | 50%，全部无法区分 |

有方向的小模型，按相似度选出的检查点在三个种子上分别匹配 8/15、6/15、7/15；
微调版分别为 7/15、6/15。它们不是 45 或 30 个新的独立测试起点，而是重复使用同一批 15 个起点。

经验近邻只从 fit 库取目标，不能读取 development 的未来；训练集自身的近邻诊断还排除了同一起点。
带方向近邻的 12/15 提示这批数据可能包含可利用线索，但只测了 15 组、未来特征整体相似度仍低，
不能认定它已经知道新房子的分支布局。额外检查了仅按左右方向取 fit 均值的后验诊断，结果为
0.151、9/15；没有把这个额外诊断混成预先登记的主对照。

不能说神经网络完全没有学习方向。训练后期，小模型三个种子的出口匹配达到 10/15、11/15、10/15；
现有规模模型曾达到 12/15。但这些阶段的整体未来特征预测更差。例如现有规模有方向模型第 700 步，
fit 相似度为 0.979，开发集房屋宏平均只有 0.252。方向区分改善与整体特征泛化没有同时改善。
这些是曲线中的探索性观察，不是最终检查点的盲测成绩，不能用最高一次结果宣称有效。

## 当前判断

1. **90 条数据可以开训，也足以发现问题。** 模型能拟合训练样本，导出后也能独立输出未来特征。
2. **目前没有通过可靠性验收。** 未来特征预测未超过复制当前状态；输入出口方向未稳定优于去掉方向。
3. **主要表现为过拟合和目标之间的权衡。** 多训练几轮、换更大模型没有自动解决；旧权重微调有所改善，仍不足以达标。
4. **不能把问题全部归因于数量。** 模型需要同时保留当前场景内容、预测出口造成的变化，
   现有绝对特征预测损失没有专门保证同一节点两出口的相对关系。下一版应检查保留当前状态的预测结构，
   以及按同一节点配对采样、显式约束正确/交换出口未来的目标；所有约束只能从 fit 数据计算。

用户要的跨 episode 熟悉度，本轮尚未验证。当前输入只是节点附近 0.7 秒的八次真实观察，
没有把之前 episode 中对该场景的经历送入预测器，也没有测试场景在线适配。
因此这次冷场景离线结果，不能直接回答“反复走过后能否越来越熟”。

扩采应优先补新的物理岔口及完整双出口、楼梯/走廊的下一地点、真实到达节点的历史，以及可用于
跨 episode 查询的过去经历；继续重复相同轨迹不能增加同等数量的独立样本。
后续按起点分组的学习曲线应同时跟踪绝对未来特征、出口匹配、训练/开发差距，不能只设一个
“采够多少条就必然有效”的门槛。先固定协议与模型修改，再逐档扩量，保留封存测试。

## 权重与复现

推荐查看的微调候选：

`output/world_model_training/branch_pilot_finetune_20261106_01/candidate_predictor.pt`

它固定来自有方向模型的种子 11，按特征指标选在第 50 步；不是在多个种子中挑一个最好成绩。
与初始世界模型比较，有 4,868,956 个参数元素发生变化。它是已训练的候选，尚未自动用于选路。

已用现有 `load_event_predictor` 接口核对全部 36 条开发输入：
原始特征输入 36×8×1152，加方向 36×2，输出 36×1152；有限且单位归一化，
CPU 导出推理与训练时 GPU 输出最大差约 1.65e-5。这个接口不需要未来目标作为输入。

原始实验目录：

- `output/world_model_training/branch_pilot_20261106_01/`：八组从头训练、预训练基线、所有原始曲线与权重。
- `output/world_model_training/branch_pilot_finetune_20261106_01/`：四组微调、初始状态、候选与推理核验。
- 各目录的 `config.json`、`authorization.json`、`input_manifest.json`、`source_manifest.json` 及
  `source_snapshot/` 固定实际使用的输入、授权和实现版本；训练集没有修改。

`results.json` 汇总全部种子，`*/history.jsonl` 保存逐次评估，`comparison.csv` 和
`learning_curves.csv` 提供便于后续绘图的汇总。结果仅支持离线诊断，未测 LightNav 导航成功率，
未测 Harness 选路收益，未测跨 episode 记忆或在线参数更新。
